# Arabic AI Text Detection - MSIS822

This is my final project for MSIS822. The goal is to use machine learning to tell if an Arabic text was written by a person or generated by AI.

## Phase 1: Project Setup and Data Acquisition

I created the GitHub repository, downloaded the dataset, checked its structure, and counted the texts in each class.

## Dataset

Source: [KFUPM-JRCAI/arabic-generated-abstracts](https://huggingface.co/datasets/KFUPM-JRCAI/arabic-generated-abstracts)

| Subset | Source rows |
| --- | ---: |
| by_polishing | 2,851 |
| from_title | 2,963 |
| from_title_and_content | 2,574 |
| Total | 8,388 |

Each source row has one human-written abstract and four AI-generated versions. The five text columns are:

- `original_abstract`
- `allam_generated_abstract`
- `jais_generated_abstract`
- `llama_generated_abstract`
- `openai_generated_abstract`

All five columns have the `string` data type in the three subsets.

## Initial Data Checks

I found no missing texts, blank texts, or fully duplicated rows within each subset.

After combining the subsets and removing spaces from the start and end of the human abstracts, I found 2,992 different human abstracts. The other 5,396 human entries repeat an abstract. Repeated human abstracts can still have different AI-generated versions.

## Class Distribution Before Cleaning

| Class | Label | Text entries | Percentage |
| --- | ---: | ---: | ---: |
| Human | 0 | 8,388 | 20% |
| AI-generated | 1 | 33,552 | 80% |
| Total | | 41,940 | 100% |

These numbers include repeated texts. I also added a `group_id` to link texts related to the same human abstract.

## Phase 2: Data Preparation and Exploration

I checked the texts for duplicates and conflicting labels. I split the data into training, validation, and test sets. Related texts stay in the same set, and I checked for text overlap between the sets.

I cleaned the Arabic text, removed Arabic stopwords, and made a stemmed version using ISRIStemmer. I kept the original text for checks that use punctuation.

| Set | Clean texts | Stemmed texts |
| --- | ---: | ---: |
| Training | 25,596 | 25,566 |
| Validation | 5,432 | 5,430 |
| Test | 5,481 | 5,473 |

The stemmed version has fewer texts because some texts became the same or had conflicting labels after processing.

I used the training data to compare text lengths, common words, two-word phrases, function words, and punctuation. I also created an Arabic word cloud for each class and a chart of word counts. Five training texts are longer than the 400-word range shown in the word-count chart.

The processed data is saved locally in `data/processed/`. The figures are in `reports/figures/`.

## Running the Notebooks

I used Python 3.8.20. The packages are listed in [requirements.txt](../requirements.txt), and the Conda environment is in [environment.yml](../environment.yml).

From the project folder, run:

1. `conda env create -f environment.yml`
2. `conda activate msis822`
3. `jupyter notebook`

Run [notebooks/data_acquisition.ipynb](../notebooks/data_acquisition.ipynb) for Phase 1, then [notebooks/data_preprocessing_eda.ipynb](../notebooks/data_preprocessing_eda.ipynb) for Phase 2. The dataset is loaded from Hugging Face. The Phase 2 notebook also needs the NLTK stopwords data, which I downloaded when running it.
